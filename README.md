## 🎯 Sobre o projeto

O **Apuração Presidencial** é uma aplicação web desenvolvida com o objetivo de apresentar, de forma simples e organizada, informações relacionadas à apuração da eleição para **Presidente da República**.

A aplicação consulta os dados disponibilizados pelo **Tribunal Superior Eleitoral (TSE)** e apresenta as informações em uma interface web desenvolvida especialmente para o projeto.

---

## ⚙️ Funcionalidades

* 🇧🇷 Apuração para Presidente da República
* 🗳️ Exibição dos candidatos
* 📊 Quantidade de votos
* 📈 Percentual de votos
* 🏛️ Quantidade de seções apuradas
* 🔄 Atualização automática dos dados
* 🌐 Aplicação disponível online
* 📱 Interface adaptável
* 🇧🇷 Identidade visual inspirada nas cores da bandeira brasileira

## 🚀 Executando o projeto localmente

Clone o repositório:

```bash
git clone https://github.com/Lucas-Oliveira-Souzaa/api_votos_pr_republica.git
```

Entre na pasta do projeto:

```bash
cd api_votos_pr_republica
```

Crie o ambiente virtual:

```bash
python -m venv .venv
```

Ative o ambiente virtual no Windows:

```bash
.venv\Scripts\activate
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute a aplicação:

```bash
python app.py
```

A aplicação estará disponível em:

```text
http://127.0.0.1:5000/
```
